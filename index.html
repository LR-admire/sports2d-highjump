常见问题

Windows 提示“已保护你的电脑”怎么办？

点“更多信息”→“仍要运行”。安装包已做数字签名，但证书是俱乐部自签名，尚未在微软建立信誉，首次下载可能触发 SmartScreen。

杀毒软件报毒 / 拦截怎么办？

便携版内含 Python 运行时与深度学习库，容易被启发式规则误报。请把下载目录加入信任，或改用安装版（误报率更低）。

换电脑还能用吗？

不能直接复制。激活码绑定机器硬件指纹，换电脑后需要复制新的挑战码，向俱乐部换取新的激活码。

训练数据存在哪里？会上传吗？

全部保存在本机程序目录的 data 文件夹（运动员档案、视频副本、分析结果）。软件不联网上传任何数据。

下载后校验失败 / 解压报错？

先核对页面上的 SHA256；不一致说明下载不完整，请重新下载。便携版建议解压到不含中文和空格的路径。
